## Core Brand Rules Quick Reference
1. **Dark Mode:** Deep Black Canvas + White "Opportunity" Wordmark + Electric Orange "X" (`#FF6B00`).
2. **Light Mode:** Pure White Canvas + Black "Opportunity" Wordmark + Electric Orange "X" (`#FF6B00`).
3. **Monochrome Mode:** Pure White Canvas + Black "Opportunity" Wordmark + Black "X" (`#000000`) *(Zero orange accent)*.
4. **Favicon Rule:** Favicons **must** always use the standalone icon-only mark; never place the full wordmark into a favicon.
5. **No Redesign:** The geometry of the OpportunityX logo is permanently locked.
